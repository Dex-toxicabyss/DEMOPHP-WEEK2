# Personal Web Exercise

A small static personal-web page built with semantic HTML and a separate CSS stylesheet as part of the Week 2 practice repository.

## Run

From the repository root, start a local server:

```bash
php -S localhost:8000 -t .
```

Then open `http://localhost:8000/personal-web/`.

## Files

- `index.html` — page markup
- `style.css` — visual styling
